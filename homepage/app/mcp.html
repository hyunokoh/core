왜 MCP 인가요?Why MCP?

MCP 는 AI 에이전트가 외부 도구를 호출하기 위한 표준 인터페이스입니다. Claude Desktop, Cursor, OpenAI Agent SDK 등 거의 모든 최신 에이전트 클라이언트가 지원합니다.

The Model Context Protocol is the standard tool-calling surface for AI agents. Once you wire up the snippet below, your agent can read live market data, place and cancel orders, and pull a Proof-of-Liabilities certificate — through the same JSON-RPC tool surface every MCP-compatible client speaks. See the full spec at modelcontextprotocol.io.

클라이언트 설정Client setup

어떤 에이전트를 사용하시나요? 탭을 선택하면 해당 클라이언트가 요구하는 정확한 설정 스니펫을 보여드립니다. / Pick your agent client below — each tab shows the exact config it expects.

설정 파일에 아래 내용을 추가하세요. 위치 / Save to: ~/Library/Application Support/Claude/claude_desktop_config.json (macOS) 또는 %APPDATA%\Claude\claude_desktop_config.json (Windows). 저장 후 Claude Desktop 을 재시작하면 모든 채팅에서 zkcex 도구를 사용할 수 있습니다. After saving, restart Claude Desktop and the zkcex tools become available in any chat. 

{
  "mcpServers": {
    "zkcex": {
      "command": "python3",
      "args": ["/Users/hoh/Documents/Projects/zkCEX/core/tools/mcp_server.py", "--transport", "stdio"],
      "env": {
        "MCP_API_KEY": "<paste_your_zkcex_api_key>",
        "MCP_API_SECRET": "<paste_your_zkcex_api_secret>"
      }
    }
  }
}

API 키는 계정 페이지 에서 발급할 수 있습니다. API keys are issued from your account page; trading and chain scopes are bound to the key, so an agent with a read-only key can list balances but receives a structured scope error if it attempts to place an order.

Cursor 는 워크스페이스 또는 글로벌 MCP 설정을 지원합니다. Cursor reads MCP servers from ~/.cursor/mcp.json (global) or .cursor/mcp.json in your project root. Cursor restarts the server when this file changes. 

{
  "mcpServers": {
    "zkcex": {
      "command": "python3",
      "args": ["/Users/hoh/Documents/Projects/zkCEX/core/tools/mcp_server.py", "--transport", "stdio"],
      "env": {
        "MCP_API_KEY": "<paste_your_zkcex_api_key>",
        "MCP_API_SECRET": "<paste_your_zkcex_api_secret>"
      }
    }
  }
}

설정 후 Cmd-Shift-P → MCP: Restart Servers. After saving, run MCP: Restart Servers from the command palette.

원격 / 셀프-호스팅 / 서버리스 환경에선 HTTP+SSE 트랜스포트를 사용하세요. For remote agents, hosted runners, or anything that can't spawn a local subprocess, use the HTTP+SSE transport on port 5560. JSON-RPC envelopes go to POST /mcp/; the same path also accepts GET /mcp/health for liveness and GET /mcp/stream for an SSE notification channel.

보호 모드 / Auth modes: --auth none (로컬 신뢰), --auth bearer (세션 토큰), --auth api-key (X-MCP-API-KEY + X-MCP-API-SECRET 헤더).

권한 범위Scopes

각 도구는 다음 권한 중 하나를 요구합니다 / Each tool requires one of these scopes:

read 잔고, 주문 내역, 거래 내역, PoL 증명 / Balances, order history, trade history, PoL proofs. trade 주문 생성 및 취소 / Place and cancel orders. withdraw 온체인 출금은 MCP 에서 노출하지 않습니다. 웹 UI 에서만 가능합니다. / On-chain withdraw is intentionally NOT exposed via MCP — use the web UI.

도구 호출시 권한이 부족하면 JSON-RPC 코드 -32001 에러가 반환되어 에이전트가 사용자에게 키 업그레이드를 안내할 수 있습니다. If your key lacks a required scope, the call returns a JSON-RPC error with code -32001 listing the scopes you DO have, so the agent can ask the user to issue a new key.

제공되는 도구Available tools

총 19 개의 도구가 노출됩니다 / 19 tools are exposed:

list_markets get_ticker get_orderbook get_recent_trades get_klines get_balance get_open_orders get_order get_my_trades place_order cancel_order cancel_all_orders get_chain_info get_chain_balance list_deposits list_withdraws get_pol_my_proof get_pol_reserves export_trades_csv

각 도구의 정확한 입력 스키마는 tools/list JSON-RPC 호출로 확인할 수 있습니다. The full JSON Schema for every tool is returned by the tools/list JSON-RPC method — your agent will discover and validate it at startup.
