온체인 / On-chain traceBulletinBoard contract

잔고 변경이 zkPoL BulletinBoard 컨트랙트에 익명 Pedersen 커밋으로 기록되는 과정을 실시간으로 보여줍니다.
Every balance change becomes an anonymous Pedersen commitment posted to the zkPoL BulletinBoard contract.

BulletinBoard 컨트랙트가 아직 배포되지 않았습니다.
The indexer is running in degraded mode. Live data appears once a contract address is configured.

동작 방식/ How this works

1. 거래소에서 입출금, 거래, 정산 같은 잔고 변경이 발생하면 지갑 API → zkpol-bridge → zkPoL Rust 코어로 전달됩니다.
Balance changes (deposit / withdraw / trade settlement) flow from the wallet API through the bridge into zkPoL's Rust core.

2. zkPoL는 변경 이벤트를 배치로 묶어 Groth16 zkSNARK 증명을 생성한 뒤 BulletinBoard.appendBatch(...) 트랜잭션으로 EVM에 게시합니다.
zkPoL packages events into batches, generates a Groth16 zkSNARK over each batch, then publishes via BulletinBoard.appendBatch(...).

3. 컨트랙트는 계정별 Pedersen 커밋(타원곡선 점)을 저장하고 토큰별 총 부채를 누적하며, 모든 배치는 prevBatchHash로 연결되어 운영자가 과거 기록을 다시 쓸 수 없습니다.
The contract stores per-account Pedersen commitments (curve points), tracks total liability per token, and chains each batch via prevBatchHash so the operator cannot rewrite history.
