사용 목적이 드러나는 설명을 짧게 적어주세요 / Short, descriptive purpose.
기본은 읽기 전용입니다. 필요한 권한만 켜세요 / Default is read-only. Enable only what you need.
read 시세·잔고 조회 / market & balance reads 필수 / always on
trade 주문 생성·취소 / place & cancel orders 자동매매 / automation
withdraw 자산 출금 / withdraw assets 위험 / high risk
출금 권한을 켜려면 정확히 다음 문구를 입력해야 합니다: I want to enable withdraw / To enable withdraw, type that phrase exactly.
0을 입력하면 만료되지 않습니다 / Enter 0 for no expiry.
